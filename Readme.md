# Rule-Based Chatbot using Python Flask

[Live URL](https://rule-based-chatbot-bi82.onrender.com/)

## 📌 Project Description
This project is a simple Rule-Based Chatbot developed using:

- Python
- Flask
- HTML
- CSS
- JavaScript

The chatbot responds to predefined user inputs using a Dictionary (Hash Map).

---

# 🎯 Internship Task Requirements Covered

✅ Infinite running chatbot  
✅ Input sanitization using `lower().strip()`  
✅ Dictionary (Hash Map) used instead of if-elif ladder  
✅ Fallback response for unknown inputs  
✅ Exit command (`bye` / `quit`)
